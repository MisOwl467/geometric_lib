# Geometric Lib

Библиотека на Python для вычисления **площади** и **периметра** геометрических фигур.

## Состав проекта

- `circle.py` — круг
- `square.py` — квадрат
- `rectangle.py` — прямоугольник
- `triangle.py` — треугольник

## Быстрый старт

```bash
git clone https://github.com/MisOwl467/geometric_lib.git
cd geometric_lib
python3
```

```python
>>> import rectangle
>>> rectangle.area(2, 3)
6
```
