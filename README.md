# Geometric Lib

Лабараторная на Python для вычисления **площади** и **периметра** геометрических фигур.

## Состав проекта

- `circle.py` — круг
- `square.py` — квадрат
- `rectangle.py` — прямоугольник
- `triangle.py` — треугольник
